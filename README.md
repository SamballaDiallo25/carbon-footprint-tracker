# carbon-footprint-tracker

 
   ## Description
 a web app allowing user's to track their carbon footprint  

   ## Tech Stack
 - Backend: [Node.js, Express.js]
 - Frontend: [React.js, CSS]
 - Database: [MongoDB]
  ## Features
 - User Registration and Login
 - User Input Collection:Users can enter Distance traveled by car (in kilometers), Number of meat-based meals per week, Weekly electricity usage (in kWh)
 - Instant CO₂ Calculation:JavaScript performs real-time calculations using simple emission factors Car travel: km × 0.21 kg CO₂, Meat meals: meals × 2.5 kg CO₂, Electricity: kWh × 0.475 kg CO₂
 - MongoDB Storage for User Data and Calculations
 - History Tracking per User
 - Visual Feedback: The app dynamically shows Individual category emissions, Total weekly emissions
